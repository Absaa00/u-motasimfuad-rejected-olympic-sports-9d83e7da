# Rejected Olympic Sports

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/u-motasimfuad-rejected-olympic-sports-9d83e7da)

Entry for the [Rejected Olympic Sports](https://make.fun/c/u-motasimfuad-rejected-olympic-sports-9d83e7da) bounty on [make.fun](https://make.fun): one funny single-line sport the Olympics turned down.

## The line

> Competitive Queue Standing: athletes hold a perfectly straight line for four hours while judges deduct points for sighing, shifting weight, or checking the time.

## How it works

`main.py` is deterministic and needs nothing but Python 3: it writes exactly
that one line to `/output/entry.txt` on every run — no network, no randomness,
no clock.

```sh
python3 main.py
```
